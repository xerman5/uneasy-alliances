# Uneasy Alliances (compañero web en español)

Versión jugable en el navegador de **Uneasy Alliances**, la expansión cooperativa hecha por fans para *Star Wars: Outer Rim*.

- Expansión original: **Mike Schoenfeld** (v2.2.01). Publicación original y PDF: https://boardgamegeek.com/thread/3058093/star-wars-outer-rim-uneasy-alliances-a-fan-made-co
- Traducción al español: **@xgruber**
- Este repositorio solo aloja la copia para poder instalarla como app (PWA) en móvil. No es un proyecto propio de quien lo publica.
- *Star Wars: Outer Rim* y sus materiales pertenecen a sus respectivos titulares. Sin ánimo de lucro.

## Instalación en el móvil

- **Android (Chrome):** menú > "Instalar app" o "Añadir a pantalla de inicio".
- **iPhone/iPad (Safari):** Compartir > "Añadir a pantalla de inicio".

Abre la página una vez con conexión para que quede disponible sin internet.
